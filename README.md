# PlayViral — Free Mini Games Portal

A static, mobile-friendly browser game portal built with HTML, CSS and JavaScript.

## Games
- Reaction Test
- Number Merge (2048-inspired)
- Ball Sort Puzzle
- Block Puzzle
- Endless Runner

## Run locally
Open `index.html` in a browser. For best results use a local static server such as VS Code Live Server.

## Deploy to Cloudflare Pages
1. Create a GitHub repository and upload the contents of this folder.
2. In Cloudflare Dashboard, go to Workers & Pages → Create → Pages → Connect to Git.
3. Select the repository.
4. Framework preset: None.
5. Build command: leave blank.
6. Build output directory: `/` (or the repository root, as prompted).
7. Deploy.

## Before publishing
- Replace `YOUR-SITE.pages.dev` in canonical URLs, sitemap.xml and robots.txt with your actual Pages URL.
- Replace `YOUR-CONTACT-EMAIL` with an email address you monitor.
- Review and expand the privacy policy and terms to reflect actual analytics, cookies and advertising services you enable.
- Add original content, accessibility checks and test every game on mobile and desktop.
- Do not add AdSense code until Google approves the site. Approval is not guaranteed.

## Notes
This project is an initial MVP starter. It does not include analytics, user accounts, multiplayer, remote scoreboards or advertising code.
